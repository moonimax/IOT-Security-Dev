활성 데이터를 분석


피해 사례 이전에 활성 데이터를 우선순위 리스트가 있음
- Linux, Window 등 각 OS에 맞게 뽑아내야하는 데이터들이 존재한다.
- shell script가 있고 그걸로 파일을 미리 덤프해 노흥ㅁ

script.sh 구성 요소

ps -ef > process_info.txt
systemctl list-unit-files --type=service > service_list.txt
cat /etc/crontab > crontab_list.txt
netstat -ntulp > netstat.txt
arp -a > arp_table.txt
cat /etc/passwd > user_info.txt
