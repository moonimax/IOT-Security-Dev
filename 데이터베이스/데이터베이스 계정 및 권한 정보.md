**Caching_sha2_password / Mysql_native_password**

- mysql 8 이전으로는 mysql_native_password 알고리즘이 사용 가능했지만 취약한 알고리즘으로 판단되어 그 이후 버전에서는 Caching_sha2_password를 사용하고 있다.





## Alter / Rollback
- ```
 - CREATE database test;
  
 - use test;
  
 - CREATE TABLE staff(
    -> id INT,
    -> name VARCHAR(20),
    -> city VARCHAR(20)
    -> );

- INSERT INTO staff  VALUES(1,'KIM','SEOUL'),(2,'LEE','BUSAN');

- ALTER TABLE staff ADD age INT;
- ALTER TABLE staff DROP age;
- ALTER TABLE staff MODIFY name VARCHAR(20) NOT NULL;
- ALTER TABLE staff ADD PRIMARY KEY (id);
  ```



**트랜잭션**
- 여러 sql이 묶인 작업단위가 트랜잭션이고 모든 묶인 작업은 최종적으로 COMMIT으로 확정하고 ROLLBACK으로 취소 가능.
- 전부 반영 또는 전부 취소 둘 중 하나만 이루어지는게 트랜잭션의 기본
- 기본적으로 MYSQL은 AUTOCOMMIT 활성화되어 있어 변경이 바로 영구적으로 확정됨.

- AUTOCOMMIT을 비활성화하여 COMMIT 전까지는 ROLLBACK으로 취소가 가능하다.


```
-- 현 세션 설정에서만 적용

MariaDB [test]> SHOW VARIABLES LIKE 'autocommit';
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| autocommit    | ON    |
+---------------+-------+
1 row in set (0.000 sec)

MariaDB [test]> SET autocommit = OFF;
Query OK, 0 rows affected (0.002 sec)

MariaDB [test]> SHOW VARIABLES LIKE 'autocommit';
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| autocommit    | OFF   |
+---------------+-------+
1 row in set (0.001 sec)

MariaDB [test]> UPDATE staff SET city = 'busan';
Query OK, 2 rows affected (0.000 sec)
Rows matched: 2  Changed: 2  Warnings: 0

MariaDB [test]> SELECT * FROM staff;
+----+------+-------+
| id | name | city  |
+----+------+-------+
|  1 | KIM  | busan |
|  2 | LEE  | busan |
+----+------+-------+
2 rows in set (0.000 sec)

MariaDB [test]> ROLLBACK;
Query OK, 0 rows affected (0.001 sec)

MariaDB [test]> SELECT * FROM staff;
+----+------+-------+
| id | name | city  |
+----+------+-------+
|  1 | KIM  | SEOUL |
|  2 | LEE  | BUSAN |
+----+------+-------+
