## 2. SQL 분류


#### DML (데이터 조작어)
- SELECT : 데이터 조회
- INSERT : 데이터 삽입
- UPDATE : 데이터 수정
- DELETE : 데이터 삭제
#### DDL (데이터 정의어)
- CREATE : DB나 테이블 생성
- DROP : DB나 테이블 삭제
- ALTER : 테이블 구조 변경
- TURNCATE : 테이블의 데이터 초기화
#### DCL (데이터 제어)
- GRANT : 권한 부여
- REVOKE : 권한 회수
