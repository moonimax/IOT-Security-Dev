# 악성코드 탐험일지

---

## 1. 악성코드도 이름이 있다 — 네이밍 스키마

악성코드가 하도 많아지니까 "얘를 뭐라고 부를까?"가 문제가 됐어요. 그래서 등장한 게 **CARO(카로)** — 악성코드 작명 규칙을 연구하는 국제 그룹.

문제는... 백신 제품마다 부르는 이름이 조금씩 다르다는 것

| 조각           | 의미       | 예시              |
| ------------ | -------- | --------------- |
| **Type**     | 뭐 하는 놈?  | `Backdoor` (뒷문) |
| **Platform** | 어디서 도나?  | `Win32`         |
| **Family**   | 집안(종류)   | `Caphaw`        |
| **Variant**  | 몇 번째 자식? | `.D`            |
| **Info**     | 추가 꼬리표   | `!nk`           |

➡️ 합치면 **`Backdoor:Win32/Caphaw.D!nk`** — 이름만 봐도 "윈도우에서 도는 Caphaw 집안 4번째 백도어구나" 하고 바로 알 수 있죠.

---

## 2. 악성코드 패밀리 명예의 전당

세상을 시끄럽게 했던 유명 "집안"들:

- **Azorult** — 정보 탈취형
- **Emotet** — 한때 "악성코드계의 넷플릭스" 소리 들을 만큼 유명했던 배포 플랫폼
- **WannaCryptor (WannaCry)** — 2017년 전 세계를 멈춰 세운 그 랜섬웨어
- **CoinMiner** — 남의 컴퓨터로 몰래 코인 캐기 ⛏️
- **gh0st** — 고전 RAT 명작
- **Dridex** — 🎯 **MS Office가 주 타겟.** 악성 매크로를 심어서 활동
- **CryptoWall** — 초창기 랜섬웨어 대표 주자

##  3. 국내 APT & 스텔스 악성코드

### 🚨 SK텔레콤 BPFDoor 해킹 사태 (2025.4)

이 사건의 핵심 키워드는 **"잠복"**.

- BPFDoor가 **2021년 8월부터 무려 987일간** HSS 서버에 숨어 있었음
- **Berkeley Packet Filter(BPF)** 기술을 악용 → 리눅스 커널 레벨 백도어로 기존 보안 장비를 유유히 우회

#### 이 녀석의 필살기

- **매직 패킷 트리거(Magic Packet)**
    - 패킷 필터링 규칙을 몰래 심어두고 → "약속된 특정 패킷"이 날아오는지 감시
    - 그 패킷이 수신되면 → 그제서야 깨어나 명령 수행
- **은폐 & 탐지 회피** — 프로세스/흔적을 꽁꽁 숨김

### 그 외 단골손님

- **MOVEit Transfer 제로데이 공격** — 파일전송 솔루션의 0-day를 노림
- **Remcos RAT** — 게임사 대상 공격 사례

#  실습 Part 2 — 랜섬웨어 해부학 (Hidden Tear)


거대한 C# 소스를 통째로 외울 필요는 없고, **"이 랜섬웨어가 무슨 짓을 순서대로 하는지"** 만 잡으면 끝.
### 랜섬웨어의 동작 순서

1. **Stealth** 창 투명도 0 + 작업표시줄 숨김 → 피해자는 뭐가 도는지도 모름
    
2. **자기 복제 & 이동** 충돌 방지를 위해 자기 자신을 랜덤 폴더로 슬쩍 이사
    
3. **비밀번호 생성** 무작위 15자리 암호 키를 그 자리에서 생성
    
4. **암호화 (핵심)**
    
    - **AES-256**으로 파일을 잠금
    - 바탕화면/문서/사진/다운로드 등 **주요 폴더를 재귀적으로 싹** 훑음
    - 지정된 확장자(`.txt .doc .jpg .png .pdf .zip ...`)만 골라서 → 암호화 후 `.locked` 꼬리표를 붙임
5. **C2로 열쇠 전송** 생성한 비밀번호 + 컴퓨터 정보를 공격자 서버로 몰래 전송 (인터넷이 끊겨 있으면? → 연결될 때까지 **끈질기게 재시도**)
    
6. **협박 연출**
    
    - 바탕화면을 협박용 이미지로 교체
    - `READ_IT.txt` 랜섬노트를 바탕화면에 투척 → _"네 파일 다 암호화했다. 복구하려면 ○○를 보내라"_ 류의 메시지

**포인트:** 피해자의 열쇠를 **공격자 서버만** 알고 있다는 게 랜섬웨어의 본질. 그래서 "백업"이 최고의 백신이다.
