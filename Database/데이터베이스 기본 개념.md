## 1. 관계형 데이터 베이스 개념

**특징**
- 실시간으로 비정형적인 질의에 대해 실시간 처리 응답 가능

## 2. SQL 분류


#### DML (데이터 조작어)
- SELECT : 데이터 조회
- INSERT : 데이터 삽입
- UPDATE : 데이터 수정
- DELETE : 특정 데이터(행) 삭제
#### DDL (데이터 정의어)
- CREATE : DB나 테이블 생성
- DROP : DB나 테이블 구조째로 삭제
- ALTER : 테이블 구조 변경
	- 기존 테이블 칼럼이 4개였다가 6개로 변경 시 관계형 데이터 테이블 특징에 의해 데이터 수정 번거로움
- TURNCATE : 테이블의 데이터 초기화
	- 테이블의 뼈대는 남기고 데이터 값만 모두 날림
#### DCL (데이터 제어)
- GRANT : 권한 부여
	- 읽기/쓰기 권한 부여(GRANT 포함)
- REVOKE : 권한 회수
#### 그 외
- COMMIT : DML 작업 내용을 데이터베이스에 영구적으로 확정
- ROLLBACK : 작업 중 취소 명령어로, 마지막 COMMIT 내용으로 되돌림
