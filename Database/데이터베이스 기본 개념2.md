
## 1. 계정 및 권한 정보 (mysql 데이터베이스)

`mysql` 시스템 데이터베이스의 `user` 테이블에는 다음 정보가 저장된다.

- 계정 이름
- 접속 허용 호스트
- 패스워드(hash)
- 권한 정보

### 계정/호스트 조회

```sql
MariaDB [mysql]> SELECT user, host FROM user;
+-------------+-----------+
| User        | Host      |
+-------------+-----------+
| test        | 192.168.% |
| mariadb.sys | localhost |
| mysql       | localhost |
| root        | localhost |
+-------------+-----------+
4 rows in set (0.001 sec)
```

### user 테이블 구조

```sql
MariaDB [mysql]> DESCRIBE user;
```

총 47개 컬럼으로 구성되며, 주요 컬럼은 다음과 같다.

|컬럼명|타입|설명|
|---|---|---|
|Host|char(60)|접속 허용 호스트|
|User|char(80)|계정 이름|
|Password|longtext|패스워드(구버전)|
|*_priv (다수)|varchar(1)|Select/Insert/Update/Delete/Create 등 각종 권한|
|plugin|longtext|인증 플러그인|
|authentication_string|longtext|패스워드 해시 저장 위치(신버전)|
|password_expired|varchar(1)|비밀번호 만료 여부|
|max_questions / max_updates / max_connections|bigint|리소스 제한 값|

### mysql 취약점 점검 시 사용하는 조회

```sql
MariaDB [mysql]> SELECT user, host, authentication_string, plugin FROM user;
+-------------+-----------+-------------------------------------------+-----------------------+
| User        | Host      | authentication_string                     | plugin                |
+-------------+-----------+-------------------------------------------+-----------------------+
| mariadb.sys | localhost |                                             | mysql_native_password |
| root        | localhost | *81F5E21E35407D884A6CD4A731AEBFB6AF209E1B  | mysql_native_password |
| mysql       | localhost | invalid                                     | mysql_native_password |
| test        | 192.168.% | *47A6B0EA08A36FAEBE4305B373FE37E3CF27C357  | mysql_native_password |
+-------------+-----------+-------------------------------------------+-----------------------+
```

### 인증 알고리즘: caching_sha2_password vs mysql_native_password

- MySQL 8 이전: `mysql_native_password` 알고리즘 사용 가능
- 이 알고리즘은 취약한 것으로 판단됨
- MySQL 8 이후: `caching_sha2_password` 사용

## 2. ALTER / ROLLBACK

### 테이블 생성 예시

```sql
CREATE DATABASE test;
USE test;

CREATE TABLE staff(
    id INT,
    name VARCHAR(20),
    city VARCHAR(20)
);

INSERT INTO staff VALUES (1,'KIM','SEOUL'), (2,'LEE','BUSAN');
```

### ALTER TABLE 예시

```sql
ALTER TABLE staff ADD age INT;
ALTER TABLE staff DROP age;
ALTER TABLE staff MODIFY name VARCHAR(20) NOT NULL;
ALTER TABLE staff ADD PRIMARY KEY (id);
```

### 트랜잭션(Transaction)

- 여러 SQL이 묶인 작업 단위
- `COMMIT` → 최종 확정 / `ROLLBACK` → 취소
- 기본 원칙: **전부 반영 또는 전부 취소** 중 하나만 이루어짐
- MySQL은 기본적으로 `AUTOCOMMIT`이 활성화되어 있어 변경 사항이 즉시 영구 반영됨
- `AUTOCOMMIT`을 비활성화하면 `COMMIT` 전까지 `ROLLBACK`으로 취소 가능 (현재 세션에만 적용)

### AUTOCOMMIT 끄고 ROLLBACK 하는 예시

```sql
MariaDB [test]> SHOW VARIABLES LIKE 'autocommit';
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| autocommit    | ON    |
+---------------+-------+

MariaDB [test]> SET autocommit = OFF;

MariaDB [test]> SHOW VARIABLES LIKE 'autocommit';
+---------------+-------+
| Variable_name | Value |
+---------------+-------+
| autocommit    | OFF   |
+---------------+-------+

MariaDB [test]> UPDATE staff SET city = 'busan';
Query OK, 2 rows affected (0.000 sec)

MariaDB [test]> SELECT * FROM staff;
+----+------+-------+
| id | name | city  |
+----+------+-------+
|  1 | KIM  | busan |
|  2 | LEE  | busan |
+----+------+-------+

MariaDB [test]> ROLLBACK;

MariaDB [test]> SELECT * FROM staff;
+----+------+-------+
| id | name | city  |
+----+------+-------+
|  1 | KIM  | SEOUL |
|  2 | LEE  | BUSAN |
+----+------+-------+
```

### 참고: sql_safe_updates

```sql
SET sql_safe_updates = 1;
```

- WHERE 절 없이 테이블을 UPDATE/DELETE 하는 것을 방지
- WHERE 절에 키(인덱스) 컬럼 조건이 있어야 하거나
- 또는 LIMIT 절이 있어야 실행 가능

## 3. GRANT / REVOKE (권한 부여 및 회수)

**계정 설정 예시**: `user0` / `P@ASSW0RD`

### 계정 생성

```sql
CREATE USER 'user0'@'localhost' IDENTIFIED BY 'P@ASSW0RD';
```

### 권한 부여

```sql
GRANT SELECT ON test.staff TO 'user0'@'localhost';
```

### 권한 확인

```sql
SHOW GRANTS FOR 'user0'@'localhost';
+---------------------------------------------------------------------------------------------+
| Grants for user0@localhost                                                                  |
+---------------------------------------------------------------------------------------------+
| GRANT USAGE ON *.* TO `user0`@`localhost` IDENTIFIED BY PASSWORD '*A81F7D6BB19855E90192CD'   |
| GRANT SELECT ON `test`.`staff` TO `user0`@`localhost`                                        |
+---------------------------------------------------------------------------------------------+
```

### 추가 권한 부여

```sql
GRANT INSERT, UPDATE ON test.staff TO 'user0'@'localhost';
```

→ 권한 확인 시 `GRANT SELECT, INSERT, UPDATE ...`로 갱신됨

### 권한 회수

```sql
REVOKE INSERT, UPDATE ON test.staff FROM 'user0'@'localhost';
```

→ 권한 확인 시 다시 `GRANT SELECT ...`만 남음

## 4. mysqldump 도구

- MySQL 백업 및 복구 도구
- DB의 **구조(스키마) + 데이터**를 SQL 파일로 추출

### 백업

```bash
[user@localhost ~]$ mysqldump -u root -p test > test_backup.sql
Enter password:
```

### 백업 파일 내용 예시 (test_backup.sql)

```sql
DROP TABLE IF EXISTS `staff`;
CREATE TABLE `staff` (
  `id` int(11) NOT NULL,
  `name` varchar(20) NOT NULL,
  `city` varchar(20) DEFAULT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=latin1 COLLATE=latin1_swedish_ci;

LOCK TABLES `staff` WRITE;
INSERT INTO `staff` VALUES (1,'KIM','SEOUL'),(2,'LEE','BUSAN');
UNLOCK TABLES;
```

### 복구

```bash
[user@localhost ~]$ mysql -u root -p test < test_backup.sql
Enter password:
```
