### 전체 구조 (4개 Phase)

|Phase|기간|목표|
|---|---|---|
|1. 리눅스+네트워크 기초|1~6주|Rocky/Kali 명령어, TCP/IP 체화|
|2. 서버 구축+하드닝|7~10주|웹서버/DB 직접 세팅, 방화벽/SELinux|
|3. 보안 솔루션 실습|11~16주|Suricata, ModSecurity, FIM(DLP 개념)|
|4. 웹취약점+정리|17~20주|OWASP Top 10, 포트폴리오화|

---

### 주차별 상세 계획

#### Phase 1. 리눅스 + 네트워크 (1~6주)

|주차|내용|실습 결과물|
|---|---|---|
|1주|리눅스 파일시스템, 권한, 사용자/그룹 관리|Rocky에 사용자 3명 만들고 그룹 권한 설정|
|2주|프로세스/서비스 관리(systemctl), 로그 위치|서비스 하나 직접 등록해보기(systemd unit 작성)|
|3주|패키지 관리(dnf), 방화벽 기초(firewalld)|SSH 포트만 열고 나머지 차단해보기|
|4주|OSI/TCP-IP 계층, TCP 3-way handshake|개념 정리 노트 작성|
|5주|IP/서브넷팅, ARP/DNS/DHCP|서브넷 계산 문제 20개 풀기|
|6주|Wireshark/tcpdump 기초|웹 접속 패킷 캡처해서 handshake 구간 직접 찾기|

#### Phase 2. 서버 구축 + 하드닝 (7~10주)

|주차|내용|실습 결과물|
|---|---|---|
|7주|Rocky에 Apache/Nginx 설치, 기본 설정|웹서버 정상 구동 확인|
|8주|MariaDB 설치, 사용자/권한(GRANT/REVOKE)|DB 계정 권한 분리 실습|
|9주|SELinux 기본 개념 및 정책 적용|웹서버에 SELinux 적용 후 로그로 차단 확인|
|10주|Kali로 Rocky 스캔(nmap) + SSH 무차별대입(hydra)|공격 시도 → Rocky 로그에서 흔적 확인|

#### Phase 3. 보안 솔루션 실습 (11~16주)

|주차|내용|실습 결과물|
|---|---|---|
|11주|Suricata 개념, 설치|Rocky/별도 VM에 설치 완료|
|12주|Suricata 룰 기본 문법|기본 제공 룰로 nmap 스캔 탐지해보기|
|13주|Suricata 룰 직접 작성|SSH 무차별대입 탐지 룰 직접 작성|
|14주|ModSecurity 개념, Apache/Nginx 연동 설치|설치 완료, OWASP CRS 적용|
|15주|ModSecurity로 SQLi/XSS 공격 차단 테스트|sqlmap 공격 → 차단 로그 확인|
|16주|FIM(AIDE) 실습으로 DLP 개념 연결|파일 변경 탐지 테스트|

#### Phase 4. 웹취약점 + 정리 (17~20주)

|주차|내용|실습 결과물|
|---|---|---|
|17주|OWASP Top 10 개념 정리|항목별 1줄 요약 노트|
|18주|DVWA로 SQLi, XSS 실습|취약점 재현 + ModSecurity로 차단까지 연결|
|19주|전체 실습 재구성 (구축→공격→탐지 시나리오)|시나리오 1개 처음부터 끝까지 재현|
|20주|포트폴리오 정리|Notion/GitHub에 실습 기록 문서화|

### 하루 2시간 활용 팁

- **평일**: 이론 30분 + 실습 1시간 30분 (실습 비중을 높게)
- **주말 중 하루**: 그 주 내용 복습 + 막혔던 부분 재시도
- 매주 끝에 "이번 주 배운 것 3줄 요약"을 노트에 남기면 나중에 포트폴리오/자소서 쓸 때 그대로 재활용 가능

### 참고 자료 (검색해서 확인하며 진행)

- 리눅스/네트워크: "생활코딩 리눅스", "널널한 개발자 네트워크" 유튜브
- Suricata: 공식 문서 Getting Started 가이드
- ModSecurity: OWASP CRS GitHub 문서
- DVWA: GitHub에서 다운로드 후 로컬 구축
